# Brent Grossman, CS361, Fall 2026
## Requirements Gathering Questions

1. Question 1
> - Q: Do you want some sort of interactive map where users mark a location, or a type of forum where users post locations, or something specific in mind?  
> - A: I was thinking interactive map where people could click on a marker and then have a discussion.  

2. Question 2
> - Q: Do you want any sort of notification system to report back to the users when the trail/road is actively being repaired or has been repaired?  
> - A: I'd love for there to be a way for a user to "monitor" a waypoint and get updates.  

3. Question 3
> - Q: For the user notification system, if creating an account is not mandatory, do you want to give the users multiple options or ways to be notified when a repair is in progress/has been completed? ex. "enter email to be notified of repair progress" "enter phone number to opt into receiving text notifications" "enter pager number to receive a notification".  This could be in a situation where a user doesnt want to create an account, but might still want to use the system to view if/when/where an issue is, and still might want to be notified in the event there is a problem without having to create an account to report issues themselves.  
> - A: I think I'm willing to say that if you want notifications, you'll have to have an account.  

4. Question 4
> - Q: Do you want a record keeping system in place to show when a previous repair was performed at any specific location?  
> - A: I'd like the repair to show up on the map for a while, like a week, marked as repaired, before disappearing.
